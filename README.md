# Akshata Birthday Surprise 💗

A simple, romantic, mobile-friendly birthday website inspired by the flow in the reference video.

## Flow

1. Welcome — "Happy Birthday, Akshata"
2. Interactive balloon popping
3. Interactive candle / wish
4. Rose bouquet
5. Swipeable "Some Sweet Moments" photo cards
6. Handwritten-style birthday letter
7. Final birthday message

## Run locally

No build tools are required.

Open `index.html` directly in a browser, or use VS Code Live Server.

## Put it on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.
7. Share the generated GitHub Pages URL with Akshata.

## Replace the sample photos

The sample memory images are:

- `assets/images/memory-1.svg`
- `assets/images/memory-2.svg`
- `assets/images/memory-3.svg`
- `assets/images/memory-4.svg`

Replace them with your own JPG/PNG files. If you keep the same filenames, no JavaScript changes are required.

For example:

    assets/images/memory-1.jpg

Then update the corresponding filename in `script.js`.

You can also replace `bouquet.svg` and `final-couple.svg` with your own images.

## Personalize the message

Open `index.html` and edit the text inside the `letter-card` and `final-message`.

The site intentionally uses only HTML, CSS and JavaScript, so it is easy to host from a personal GitHub repository.
